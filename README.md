# CTD Navigator Pro

面向 ADC/CDMO 的 CMC Regulatory Affairs 新人和项目团队：检索报告、检测、缩写或法规术语，获得 ICH CTD Module 3 的建议章节、中英文名称、审阅要求、交叉引用和公开监管依据。

## 功能

- 205 个结构化条目：45 类报告/研究、97 类检测项目、39 个专用术语与证据专题、24 个工艺开发与 QA 工作场景
- 54 个 M4Q(R1) Module 3 叶级章节的中英文地图
- 支持中英文、缩写和近似输入，例如 `原料放行`、`包材放行`、`CoA`、`CCI`、`CIU`、`PPQ`
- DS / DP 视图切换
- IND / BLA 阶段成熟度提示
- 一对多章节映射：区分“主要”与“交叉”位置
- 明确区分“CTD 提交证据”和“通常留在现场的 GMP/PQS 文件”
- 中英文审阅要求、法规指南矩阵和 M4Q 章节反查
- 可筛选、可下载的 CSV 术语库
- 可编辑并导出的项目资料清单
- 公开 ICH/FDA 链接、明确免责声明
- 本地规则检索，不上传文件，不含企业敏感数据

## 本地运行

需要 Python 3.8+。在本目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器通常会自动打开 `http://localhost:8501`。

## 测试

测试使用 Python 标准库，无需额外安装测试框架：

```powershell
python -m unittest discover -s tests -v
```

## 内容边界

本工具提供导航和培训辅助，不构成法规、法律或申报建议。CTD 位置可能因产品、地区、文件内容和申报策略而变化，最终归档应由项目 RA/CMC 专家确认。

## 法规版本说明

生产导航使用已实施的 M4Q(R1) 编号。截至 2026 年 10 月，M4Q(R2) 仍处于 Step 3 草案阶段，不应作为现行归档结构实施；应用仅作前瞻提示。

## 后续 RAG 扩展

建议保持当前确定性映射作为“章节护栏”，再增加：公开指南分段检索、带原文定位的回答、公司批准语料的权限隔离、引用有效性检查、审计日志与人工确认。不要让生成模型直接覆盖人工维护的章节映射。

## FDA IID 文件导入

应用新增“FDA 辅料库 / IID”页面。到 FDA 官方下载页获取 IID 的 ZIP 或 CSV/TXT 文件，填写实际发布版本，预览后点击确认导入。支持逗号、波浪号和制表符等分隔文本，以及 XLSX 主数据。ZIP 自动识别主数据并排除变更日志。导入保留给药途径、剂型、CAS、UNII、Potency 原始数值和单位及附加列，记录文件 SHA256 与 UTC 导入时间，仅去除完全相同记录。

快照保存在项目 data/fda_iid.json，供本机应用使用；后续导入替换该快照。人工 RA 术语库独立保存。IID 页面支持名称/CAS/UNII 检索、PS80/PS20 别名、途径和剂型筛选及 CSV 导出。

已下载并导入 FDA 当前下载链接的 2026-10 版本，共 9,076 条记录、1,795 个辅料名称。原始 ZIP 保存在 data/fda_iid_2026_10.zip，主数据为 IIR_OCOMM.xlsx。此前附件访问失败，经重试已成功；测试数据不会写入正式库。上传文件仅做结构校验，不能自动认证来源。用户应从官方页面获取文件并确认版本。IID 不是 FDA 全部数据库，也不含完整检测/开发证据或逐项 RA 解释。

## 工艺开发与 QA 工作场景

新增 12 个工艺开发和 12 个 QA 场景，支持中英文名称、缩写及常见问题别名检索。结果展示定义、场景、RA 判断路径、证据清单、升级讨论信号、风险及边界和 IND/BLA 重点；术语库 CSV 同步导出工作场景内容。

工艺开发：缩小模型、DoE、放大、技术转移、场地转移、参数超范围、返工/重新加工、收率物料平衡、中间体标准、一次性系统、混合和冻干。

QA：CAPA、质量风险评估、质量协议、数据完整性、审计追踪、版本控制、承诺跟踪、OOS 无效化、稳定性异常、供应商变更、迎检和管理评审。

QA 场景的 CTD 关联仅表示影响相关时的交叉示例，不表示内部记录需要逐份申报。报告类别、时限和地区要求需针对具体变化判断；不能根据条目自动批准放行、返工或延期。本批为依据指南原则整理的 RA 场景解释。
